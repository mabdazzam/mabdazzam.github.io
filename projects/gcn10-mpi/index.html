GCN10 parallel raster processing

Research software · released

Alongside the GCN10 data product, I developed a C and MPI processing framework for large-scale Curve Number raster production, plus a Python interface. This work addresses the computational challenge of producing and using high-resolution global geospatial datasets.

The data product and the parallel-processing software are related but distinct contributions. The MPI implementation distributes raster blocks across ranks, computes Curve Number conditions in parallel, and writes the resulting global rasters.

For the full global dataset, the published benchmark estimates roughly 322 days for serial Python under comparable I/O conditions. The C/MPI production run completed in 12 hours 48 minutes. The Python figure is an extrapolation from the measured benchmark, rather than a 322-day run.

OpenMP and MPI performance

Benchmarks compare hybrid MPI/OpenMP runs with MPI-only scaling. In these tests, adding OpenMP threads did not consistently reduce runtime; MPI rank scaling provided the clearer performance gains.
