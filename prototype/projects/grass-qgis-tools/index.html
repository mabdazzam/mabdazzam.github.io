GRASS and QGIS hydrology tools

Open-source software · ongoing contributions

I develop and contribute geospatial tools that make common hydrologic workflows easier to run in open-source GIS. This work spans GRASS add-ons for Curve Number generation, runoff estimation, and time of concentration, along with QGIS tools for Curve Number generation and Manning's roughness mapping.

I participated in the GRASS Developer Summit at North Carolina State University in Raleigh, May 19–24, 2025. The week brought GRASS contributors together for collaborative development, documentation, and project planning.
