Hydrology tools for GRASS GIS and QGIS

I develop tools that turn hydrologic methods into repeatable GIS workflows. My published contributions include three GRASS raster add-ons and two QGIS plugins spanning Curve Number generation, event runoff, travel time, and Manning's roughness.

GRASS GIS add-ons

01 / RASTER

r.curvenumber

Generates Curve Number rasters from land cover and hydrologic soil groups, with selectable hydrologic and antecedent runoff conditions.

Documentation ↗
02 / RASTER

r.runoff

Estimates event runoff depth and volume from Curve Number and rainfall; optional routing inputs support upstream totals and peak-discharge estimates.

Documentation ↗
03 / RASTER

r.timeofconcentration

Maps travel time using longest upstream flow paths and the Kirpich equation, with optional diagnostic rasters for length, drop, and slope.

Documentation ↗
