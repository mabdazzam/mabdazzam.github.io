# Research profile prototype

This is a local, static HTML/CSS research profile inspired by Craig Ferguson's spare, text-first personal site, with visual cues from WaterAI and Yifan Cheng. Open `index.html` directly or serve this directory with any static web server. No build tools or dependencies are needed.

The homepage leads with four representative contributions, then separates active applications, research areas, figures, software/data, and publications. Each project has its own folder under `projects/`, with an `index.html`, a short `README.md`, and selected figures in `assets/`. To add another study, copy a folder, replace its text and images, and add a link to the appropriate homepage group.

The prototype is separate from the existing root site files so their current local edits remain untouched. Scientific figures are local copies of work already in the project directories. The Rio Grande, CONUS, and Mesilla pages state which figures show exploratory results or model setup rather than validated findings.
